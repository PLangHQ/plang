Data — the value the goal returns, given whenever the step names one to return (`return %result%`) — a `%!…%` system variable is a value too (`return %!goal%` → Data=%!goal%). Leave it out, an empty `goal.return()`, only when the step names no value to return.
Depth — how many goal levels to leave; left out unless the step says how far (1 leaves the current goal).
