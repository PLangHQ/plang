Keeps an actor's settings for the runs after this one. A setting is read from what it configures, always under `.setting` (`%!app.goal.list.setting.os%`, `%!llm.setting.cache%`, `%!llm.query.setting.cache%`), and changed for this run with `set %!llm.setting.cache% = value` — that is the variable module, never this one. This module only saves a setting whole as the actor's row, or removes that row.
