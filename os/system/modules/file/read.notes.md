Path — the file to read · say: the path, inline · builder: as the step writes it
Template — the kind of template the file's text is: plang fills its %variables% from memory · say: load vars, fill in the variables, with variables · ask: does the step EXPLICITLY say to fill in the file's %variables% (the words "load vars" / "fill in" / "with variables")? if it does not, the answer is none · builder: plang ONLY when the step says to load or fill the file's variables; a plain read — `read file '…', write to %x%`, a .json or any structured file included (the extension never asks for it) — names none of these and leaves Template out
Returns — the file's content. A JSON file is navigable; it is parsed when first navigated.
