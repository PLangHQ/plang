A — the value that must be larger: the one named BEFORE "greater than" (`assert %n% is greater than 5` → A=%n%).
B — the value it must exceed: the one named AFTER (`… greater than 5` → B=5).
Message — only when the step names a custom error message (the quoted text after the comma).

- `assert A is greater than B` is A before, B after. Never the other way round.
