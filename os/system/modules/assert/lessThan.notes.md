A — the value that must be smaller: the one named BEFORE "less than" (`assert %n% is less than 5` → A=%n%).
B — the value it must stay under: the one named AFTER (`… less than 5` → B=5).
Message — only when the step names a custom error message (the quoted text after the comma).

- `assert A is less than B` is A before, B after. Never the other way round.
