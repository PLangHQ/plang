## New smells in these commits (`app/start` included)

1. **A flag's flag-ness is packed into the property's Name** (`start/property/this.cs`: "a flag written `--x` is `!x`, a property written `x=…` is `x`"). It is a second answer carried in a Name, the same shape as v3 §5. The `!` is then asked back by prefix: `start/this.cs:692` `p.Name.StartsWith('!')`, `:694` `flag.Name[1..]`, `Executor.cs:88` `property.Name.StartsWith('!')`, `Executor.cs:62` `word.Name[1..]`, and the mode table is keyed `"!debug"/"!test"/"!build"` (`Executor.cs:54-56`). Root: the property answers `IsFlag`, its `Name` is the bare name, and the Executor's modes and `Set` ask `IsFlag` (no prefix to build, slice or test).
2. **Null means "the line gave none"** (`start/property/list/this.cs:579,583` return `null` on a miss; `Executor.cs:105,114` `start.property["path"] == null`). A sentinel read at the call site, and `start.Goal == null`/`Goal ?? "Start"` the same. Root: `Has(name)` on the list (the dict already has `Has`, `item/dict/this.cs:174`).
3. **`Set` silently depends on the caller having removed the mode words first** (`Executor.cs:59-62` `modes.Keys.Select(start.property.Remove)…ToList()`, a LINQ `Select` that mutates the start; then `start.Set` finds every `!…` property and refuses a mode word that no setting names). The order is the contract, and `Remove` is a mutation on a value that was documented as "read once". Root: `Set` takes what to leave out (or the Executor passes the words it handled), and the mode words are read, not removed.
4. **`Items()` is a method where the list convention is `.list`** (`start/property/list/this.cs:576`; the repo says enumerate with `app.X.list`). Low; a name fix.
5. **`Birth(result, other)`** (`number/this.Arithmetic.cs:42`, `number/this.cs:204`) is a noun used as a verb for "give this result its type"; **`declaration`** (`module/variable/set.cs:183`) holds a type entity and is again a role word of the `declared` family. Both low; name for what each is or returns.
6. **Moved, not new, so noted only:** `word.Value is IDictionary<string, object?>` and `word.Value is not false` (`Executor.cs:63,74`) ask the raw value what it is; the property could answer. `Executor.cs:106,137` `TrimStart('/', '\\')` at two consumers (v3 §8, not in A).
